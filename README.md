# 🤖 AI Resume Builder

An AI-powered application that helps users create professional resumes tailored to modern job market requirements.

## 🚀 Overview

AI Resume Builder allows users to generate structured resumes based on their skills, experience, and career goals. The project focuses on automation, clean API design, and user-friendly resume generation.

---

## ✨ Features

* Resume generation from user input
* Professional resume formatting
* Skills and experience organization
* REST API built with FastAPI
* JSON-based resume output

---
